# D1–D8: the original design calls

Answered by the captain against the first scout report. He took the
recommended option on all eight, which confirms contentment with the defaults,
not that each alternative was weighed; D1 and D3 were flagged for a second look
once there is real usage.

| # | Question | Decision | Status |
|---|---|---|---|
| **D1** | Where is the gate on by default? | **Opt-in per project.** Governed only where `.no-deceit/` exists (`nd init`); everything else is ungoverned. `FM_TASK_ID` and headless exemptions stay as belt and braces. | Stands. The *default tier* implicit in D1 (Tier 1) is **reversed** by [R1](r1-r8.md#r1): a governed project now starts at Tier 2. |
| **D2** | Is Tier 3 a grant or a setting? | **A grant that expires** at session end or a time box, then falls back to the project default. | Stands. |
| **D3** | May the developer override a `not_yet` unlock? | **Yes, with a typed reason, ledgered.** One appeal per verdict. | Stands. |
| **D4** | Is an LLM grader acceptable on unlock? | **Yes: a blind fresh-process grader** behind a deterministic pre-filter. | Stands; extended to the transfer rubric ([R3](r1-r8.md#r3)). |
| **D5** | Police code in chat at Tier 1? | **`Stop`-hook check plus on-screen redaction** (Claude Code only). Snippet threshold left open: config default `tier1MaxFenceLines = 6`, tuned from the ledger. | Stands. |
| **D6** | Core language | **Node `.mjs`, zero dependencies**, imported in-process by the OpenCode and Pi adapters. | **Reversed** at the captain's instruction: the core moves to Babashka, incrementally, by the captain's own hand (see [R8](r1-r8.md#r8)). Node remains the shipped runtime, and the oracle, until each namespace is cut over. |
| **D7** | Naming | **Rename the repo to `no-deceit`** before a plugin id is published. | Stands (done). |
| **D8** | firstmate integration depth | **Exemption only, for now.** Crewmates are exempt and ledgered as "delegated"; `learn:` backlog reserve tagging stays a later idea. | Stands. |

## What each still means in the code

- D1: `core/scope.mjs` Step 0 (no `.no-deceit/` → not governed). `nd project add` and `nd init` are the only ways in.
- D2: the session overlay carries a Tier 3 `expires_at`; `SessionStart` and each `PreToolUse` check it.
- D3/D4: pre-filter → blind grader → `unlocked | not_yet` → optional appeal → optional typed override, every step ledgered (`core/grader.mjs`).
- D5: `core/fence.mjs`, `Stop` and `MessageDisplay` in `hooks/nd-hook.mjs`.
- D8: `core/scope.mjs` worker exemption; `nd report` "Delegated".
