# Decisions

Settled product calls, recorded so the reason survives the conversation that
made them. Two rounds: **D1–D8** (the original scout report, all answered by
the captain) and **R1–R8** (the redesign report). Where a later call reverses an
earlier one, both files say so.

| File | Contents |
|---|---|
| [d1-d8.md](d1-d8.md) | The original design calls, with their current status (two reversed). |
| [r1-r8.md](r1-r8.md) | The redesign calls, R8 as the captain actually decided it. |

Each decision names what it changed in the code and where it lives.
Enforcement posture, for all of them: hooks target a cooperative agent and
ordinary input, not an adversary — "it's No Deceit, so even just warning and
flagging the consequences is enough" (captain).
